# Plinth — Duchess

Plinth turns the Duchess renovation Telegram conversation into a structured project record. It keeps workstreams, room details, schedules, deliveries, decisions, actions, and blockers in one mobile-friendly dashboard.

The production site is available at [plinth-duchess.vercel.app](https://plinth-duchess.vercel.app/).

## How it works

- Telegram messages are collected throughout the day.
- At 11:00 PM Singapore time, Plinth interprets the day as one contextual session.
- Decisions, actions, blockers, progress, and clarifications are added to the Project Record.
- Record statuses can be updated by the owner without changing the historical conversation.

Private environment values are configured in Vercel and are never stored in this repository.
